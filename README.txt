병현이의 긍정카드 v2.0 — GitHub Pages 배포 안내

1. ZIP 압축을 해제합니다.
2. GitHub 저장소의 최상위(root)에 index.html, script.js, cards.json, manifest.webmanifest, icon.svg, images 폴더를 그대로 업로드합니다. ZIP 파일 자체를 올리면 안 됩니다.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. 배포 주소(예: https://사용자명.github.io/positive-cards/)로 접속합니다.
5. 첫 접속은 카드 미표시, 첫 카드 뽑기, 10장 랜덤, 설정에서 이름 변경, YouTube 듣기를 시험합니다.
6. Android Chrome: 브라우저 메뉴 > 홈 화면에 추가 또는 앱 설치. iPhone Safari: 공유 > 홈 화면에 추가. 브라우저/OS에 따라 메뉴 명칭이 다릅니다.

주의: 이 앱은 온라인 전용입니다. service worker를 사용하지 않습니다. 이름 변경은 해당 브라우저에서만 유지되고 새로고침하면 기본값으로 돌아갑니다. 이름을 링크에 담고 싶으면 ?name=이름을 주소 끝에 붙일 수 있습니다. 공개 저장소에 개인 정보를 저장하지 마세요.

자수풍 이미지는 글자 없는 SVG 벡터 일러스트 시제품입니다. 확정된 캐릭터의 정교한 실사 자수 이미지가 아닌 임시 제작 이미지이며, 나중에 파일명 그대로 고화질 이미지로 교체할 수 있습니다.
